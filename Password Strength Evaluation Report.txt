Password Strength Evaluation Report
 
This report demonstrates how password complexity affects overall security. Multiple passwords with different lengths and character combinations were created, tested using a password strength checker, and analyzed based on feedback and crack-time estimates.

P4	A$nW!n_20#48XY	  15	         Very Strong (all character types + long)


Best Practices Learned

From the evaluation and feedback, the following best practices were identified:

 Use 12–16+ characters

Longer passwords increase entropy and exponentially slow down brute-force attacks.

 Mix character types

Include:

Uppercase
Lowercase
Numbers
Symbols

 Avoid predictable patterns

Don’t use-
Names
Birthday years
123, password, “qwerty”, etc.

Use multi-factor authentication (MFA)

Even if a password is guessed, MFA prevents unauthorized access.

Common Password Attacks

1. Brute-Force Attack

Attacker tries every possible combination
Short or simple passwords are cracked instantly

2. Dictionary Attack

Uses lists of common words, passwords, and leaked data
Predictable passwords like names, years, and simple patterns break quickly

3. Hybrid Attacks

Adds numbers/symbols to dictionary words
Example: “Anwin123!” can still be cracked

4. Credential Stuffing

Uses leaked email/password combinations
Password reuse makes this method very dangerous
